# Nasirat Balogun | Portfolio
React + Vite + Tailwind v4 + React Router (JavaScript)

    npm install
    npm run dev

- Content: `src/data.js` (add her LinkedIn URL in `me.linkedin`)
- Photo: save as `public/photo.jpg` (portrait, ~800x1000)
- CV: save as `public/Nasirat_Balogun_Resume.pdf`
- Colours and fonts: `src/index.css` under `@theme`
- Hosting: `npm run build`, upload `dist/`. `public/_redirects` (Netlify) and `vercel.json` make page refreshes work.
